## Why

Employees and company admins need a way to recover from common workflow and installation problems from the screen where they get stuck. Support escalations should carry a useful reference without exposing HR records.

## What Changes

- Add signed-in help with steps and shortcuts for access, approvals, payroll, attendance and server recovery.
- Explain account state and route company administration to the roles that can make changes.
- Offer a shareable, allowlisted diagnostic summary and an editable owner support email.
- Link recoverable API errors, payroll issues and owner system diagnostics to relevant help.

## Capabilities

### Modified Capabilities

- `self-hosting` adds in-app recovery guidance and shareable diagnostics.

## Impact

Web app, demo routing, user documentation and browser tests. The existing permissions and system-status endpoint apply.
