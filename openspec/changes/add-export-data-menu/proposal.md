## Why

Users need one place to find generated data and files for reconciliation, analysis and filing.

## What Changes

- Add an Export data menu with direct Excel, CSV and JSON downloads for permitted reports.
- Add detailed payroll, leave, and attendance datasets and entries for outputs with established download workflows.
- Keep generated PDFs and filing files available in their native formats.

## Capabilities

### Modified Capabilities

- `reporting`: export discovery, structured JSON downloads and additional report datasets.

## Impact

Reporting, payroll, leave, the web shell and operator documentation.

## Non-goals

Raw database dumps, access changes, and conversion of bank or filing formats into spreadsheets for submission.
