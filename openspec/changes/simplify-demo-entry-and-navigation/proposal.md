## Why

Visitors need a chance to choose a language before the demo loads. The demo controls and reporting links also need clearer grouping.

## What Changes

- Show a language chooser and a Start demo button before booting a new demo tab.
- Put sandbox controls under Demo options. Explain captured email where visitors can use it.
- Add a Reporting heading above Reports and Export data.

## Capabilities

### New Capabilities

- `demo-entry-and-navigation` defines the demo entry screen and navigation.

### Modified Capabilities

## Impact

The public demo entry point and toolbar, the shared navigation and demo password reset feedback, and the demo documentation.

## Non-goals

Changes to email delivery, reporting permissions or the native apps.
