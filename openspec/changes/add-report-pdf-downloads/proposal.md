## Why

HR teams need printable copies of the reports they run, identified by their own company branding.

## What Changes

- Add a PDF download to each report and its shortcut in Export data.
- Print the company name and its configured logo, the report filters, all matching rows, and any report totals and notes.

## Capabilities

### New Capabilities

- `reporting`: Add branded report PDFs to the existing report export workflow.

## Impact

The core report exporter, web report download controls, OpenAPI reference, and reporting guide change. Report permissions and audit logging apply to PDF downloads.

## Non-goals

Employee directory and other data exports keep their existing formats.
