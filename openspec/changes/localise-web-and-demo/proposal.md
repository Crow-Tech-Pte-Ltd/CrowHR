## Why

Crow HR users should be able to operate the web app in any of Singapore’s four official languages. The public demo should make it just as easy to try each language.

## What Changes

- Add English, Simplified Chinese, Malay and Tamil language options to the web app and the demo.
- Let visitors set a language before signing in and let signed-in members change it from their own account menu.
- Translate web interface copy and the demo’s own controls. Keep the Company profile guidance beside the fields needed for payroll setup.

## Capabilities

### New Capabilities

- `web-localisation` covers language selection, preference persistence and web message rendering.

### Modified Capabilities

## Impact

The change affects the shared React app, its UI components and the demo entry points.

## Non-goals

Native app translations, documentation translations, generated documents, statutory export schemas and translation of organisation-entered content.
