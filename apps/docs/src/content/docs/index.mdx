## What it does

People records, leave, attendance and overtime, expense claims, shift rosters, documents and HR letters, approvals and reports. Monthly payroll with CPF (OW and AW ceilings, SPR graduated rates), SHG funds, SDL and an FWL estimate, itemised payslips, and the CPF EZPay file, a bank file and an IR8A export that you upload yourself. Each CPF figure shows its working, the rate table it used and a link to CPF's source. Staff sign in with email and password and two-step verification, Google Workspace, Microsoft Entra ID, any OpenID Connect provider, or Singpass once your company has onboarded with Singpass.

## Install

You need Docker with the Compose plugin. Get the files, set `PUBLIC_URL` in `.env`, and start:

```sh
git clone https://github.com/Crow-Tech-Pte-Ltd/CrowHR.git && cd CrowHR
cp .env.example .env
# edit .env: set PUBLIC_URL, e.g. https://hr.example.sg
docker compose up -d
```

The first start prints a one-time setup code (`docker compose logs app | grep -A3 'SETUP CODE'`); open `PUBLIC_URL` and enter it to create your company and its owner. Crow HR runs as one app container and PostgreSQL 17, with no Redis, no queue and no cloud account. The [quick start](/docs/quick-start/) has the details.
