<span class="crow-pill crow-pill--soon">Coming soon</span>

A public demo at hr.crow.sg is planned but does not exist. The design is to run the same web app and the same API code entirely in the visitor's browser against an in-browser PostgreSQL (PGlite), seeded with fictional data, isolated per visitor and resettable, so nothing a visitor types reaches a server. Parts of the groundwork are in place (the API core has no Node-only dependencies, and a demo password hasher exists), but the demo package and app are not built. To try Crow HR today, [install it](/docs/quick-start/).

Progress is tracked on the [project status](/docs/status/) page. Nothing on this page is available in the current version.
