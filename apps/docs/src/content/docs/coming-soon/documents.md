The document store is specified (`openspec/changes/add-documents`) but not built; the Documents screen is an empty placeholder. The plan covers per-employee documents in categories with visibility rules and medical sensitivity, expiry reminders, HR letters and Key Employment Terms generated from templates, and employee acknowledgements. Payslip PDFs, which do exist, are covered in [payslips](/docs/payroll/payslips/).

Progress is tracked on the [project status](/docs/status/) page. Nothing on this page is available in the current version.
