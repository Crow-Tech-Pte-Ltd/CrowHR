<span class="crow-pill crow-pill--soon">Coming soon</span>

Clock-in, timesheets and overtime capture are not built yet; the Attendance screen is an empty placeholder and the module still needs its specification. Overtime pay itself is computed today: payroll applies the Employment Act Part 4 overtime rules from the statutory engine to overtime minutes that a payroll admin enters by hand on each run. When attendance exists, approved overtime and scheduled days will flow into payroll instead of being typed in.

Progress is tracked on the [project status](/docs/status/) page. Nothing on this page is available in the current version.
